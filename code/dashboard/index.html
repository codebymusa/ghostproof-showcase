New to GhostProof? How it works & what to look for

A successful deletion job can leave old-email copies or a path that recreates data. Start with Mira, then Talin, then Niva. Nothing here connects to real customer systems.

Pipeline: fictional request → current/historical identity → source-supported facts → state at the cutoff → explicit policy → findings, proposed remediation and verification.

AI's specific role: optional local source-line selection. Deterministic code extracts and validates facts; the model never decides the verdict. Offline baseline needs no model. AI mode adds a separate handover note, so it is a different evidence corpus.

Read the evidence: a system is an application; a resource is a record or process. Observed time and capture/availability differ. Claims do not establish absence. COMPLETE is limited to this fictional corpus; INSUFFICIENT_EVIDENCE means no supported verdict, not a hidden pass.
